# 📖 MANUAL DE USO: FERRAMENTA RESPONSA 2.0

**Descrição:** A RESPONSA é uma ferramenta de linha de comando (CLI) desenvolvida em Python para investigações em fontes abertas (OSINT).
**Aviso Ético:** Esta ferramenta deve ser usada apenas para fins educacionais e em alvos que você tenha autorização explícita.

## 🚀 Como abrir a ferramenta
Sempre que fechar o Termux:
1. Digite: cd "responsa 2.0"
2. Digite: python -m responsa

## 🕵️‍♂️ Módulos Disponíveis
1 a 14: (Usuário, Email, CEP, Telefone, Nome, IP, WHOIS, Subdomínios, CNPJ, Link, Hash, Imagem, CPF, Dono de Telefone).

## 📄 Relatórios HTML
Para salvar: digite s quando perguntado.
Para ver no celular: cp responsa_resultados/arquivo.html /sdcard/Download/
